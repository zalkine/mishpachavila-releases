# משפחבילה – הורדות

כאן נמצאות רק קובצי ההתקנה (APK) של האפליקציה משפחבילה, וקובץ `latest.json` שבעזרתו
האפליקציה בודקת אם יש גרסה חדשה. אין כאן קוד מקור ואין מידע אישי.

התקנה ראשונה: הורידו את הקובץ האחרון מתיקיית `apk/`. עדכונים הבאים מגיעים מתוך האפליקציה.

This repository only holds the app's APK files and `latest.json` (used by the app's
in-app updater). No source code, no personal data.
